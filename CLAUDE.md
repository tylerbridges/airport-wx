## Orchestration (this repo)

- Main model for routine work here: Sonnet 5.5. Recommend Opus 5.5 only for architecture, data-shape/API logic changes, or a piece Sonnet failed twice.
- Auto-delegation is narrow: only a researcher for doc-heavy reading, or implementers for 2+ independent parallel pieces, and only when that beats doing it in the main session. Never auto-spawn senior-implementer or verifier.
- Verifier only for risky diffs: data-source/API swaps, deploy/Pages/workflow config, secrets, deletions, or many-file changes.
- At most 3 subagents without asking; no Fable (architect) without asking.
